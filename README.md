### **Data Professional Survey Dashboard** [https://github.com/yussufm123/Dashboards/tree/main/DP_Survey]

I created a Power BI dashboard analyzing survey data from data professionals worldwide. This dashboard provides insights into demographics, compensation, job satisfaction, and technology preferences across the data industry.

Tools Used: Power BI, Power Query, Data Visualization.

### **HR Analytics & Employee Attrition Dashboard** [https://github.com/yussufm123/Dashboards/tree/main/HR_Analytics]

I created a comprehensive Power BI dashboard analyzing employee data to track workforce metrics, demographics, salaries, and attrition trends. This dashboard provides key insights into employee turnover patterns across different job roles and departments to help drive data-backed retention strategies.

Tools Used: Excel, Power Query, Power BI, Data Visualization.
